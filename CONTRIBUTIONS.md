# Вклад и использование ИИ

Проект выполняется пользователем elizavetamalahova для университетского доклада. Цель этой страницы — отделить решения и артефакты, которые можно проверить, от неподтверждённых утверждений о ручном авторстве.

## Решения пользователя, зафиксированные в рабочем обсуждении

- Постановка задачи: исследовать шардинг и добавить обучение с подкреплением.
- Требование работать с реальными локальными данными и воспроизводимыми ноутбуками.
- Решение добавить настоящую нейросеть после табличного Q-learning.
- Решение перейти от hits_v1 к более содержательному эксперименту на Twitter cache traces.
- Требование уменьшить перегрузку, а не оптимизировать только суммарную стоимость.
- Решение публиковать проект для оценки преподавателем.

## Использование Codex/ИИ

Код, тесты, ноутбуки, подбор гиперпараметров, локальное выполнение экспериментов и первоначальные тексты документации подготовлены с существенной помощью Codex. Нельзя представлять весь этот код как вручную написанный студентом. Пользователю предстоит самостоятельно проверить понимание алгоритмов, интерпретацию результатов и выполнить требования преподавателя к раскрытию использования ИИ.

Метрики получены выполнением кода на реальных трассах, а не придуманы. Модельные затраты не являются измерениями реального ClickHouse. Ограничения и отрицательные результаты сохранены.

## Как будет отражаться дальнейший вклад

Git-история начинается с текущего состояния проекта. Первоначальные этапы доступны в истории Git; фиктивные прошлые коммиты и даты не создаются. Дальнейшие изменения следует фиксировать отдельными коммитами с причиной изменения и проверкой. Для новой серии опытов сохраняйте отдельный протокол, параметры, seed, веса и таблицы; не заменяйте прежние результаты без пояснения.

## Исправления после внешнего отзыва

Пользователь поставила задачу самостоятельной переработки без использования реализации другого ассистента. В этой работе код, эксперименты и отчёты продолжения исследования подготовлены с помощью ИИ-ассистента; сравнение с кодом Claude не проводилось. Результаты не являются доказательством самостоятельного ручного написания всего кода студентом. Все запусковые данные и отрицательные результаты сохранены.
